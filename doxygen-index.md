# FrostWing Documentation

### Welcome to the FrostWing docs! 📚

Whether you're here to fix a bug, add a feature, or just poke around the code, this is the place to start. You'll find everything from header files to API references, all in one spot.

---

### Before You Dive In

Have you read [CONTRIBUTING.md](https://github.com/Frost-Wing/osdev/blob/main/CONTRIBUTING.md) yet? Give it a quick read first. It'll save you (and us) a lot of headaches later.

> **Note**
> This isn't an intro to FrostWing itself. If you want to learn about the OS, head over to the [README](https://github.com/Frost-Wing/osdev/blob/main/readme.md) or use the sidebar.

---

### What You'll Find Here

This site is a full archive of the FrostWing codebase documentation, including:

- Every variable, function, class, and struct defined in the OS
- Doxygen comments
- Dependency lists and graphs
- The header files themselves
- The directory hierarchy
- ...and plenty more

---

### How to Find Your Way Around

Not sure where to start? Here's a quick guide:

| If you want to... | Look at... |
|---|---|
| See what a function or struct does | **Functions / Classes / Structs** in the sidebar |
| Understand how files relate to each other | **Dependency graphs** on each file's page |
| Browse the source layout | **Directory hierarchy** |
| Read the actual headers | **Files → Header files** |
| Search for something specific | The **search bar** at the top |

**Pro tip:** Dependency graphs are great when you're about to change something and want to know what else might break.

---

### Reading the Docs

Most of this site is generated automatically from comments in the source code using Doxygen. That means:

- **The docs are only as good as the comments.** If something is unclear or missing, that's a great first contribution!
- **They stay in sync with the code.** When the code changes, the docs get regenerated.
- **Found a typo or outdated description?** Fix it in the source comment, not on this site.

---

### Ready to Contribute?

Here's a simple path to your first contribution:

1. Read [CONTRIBUTING.md](https://github.com/Frost-Wing/osdev/blob/main/CONTRIBUTING.md)
2. Fork the repo and clone it locally
3. Browse these docs to find the part of the OS you want to work on
4. Make your changes and write clear Doxygen comments for anything new
5. Open a pull request and tell us what you changed and why

Not sure what to work on? Check the [issues page](https://github.com/Frost-Wing/osdev/issues) for something that looks interesting.
